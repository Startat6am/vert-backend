# vert-backend

Рендерер коротких вертикальных AI-видео. Первый тестовый ролик — сценарий «Как ИИ создаёт ответ?» из репозитория [vert-gen](https://github.com/Startat6am/vert-gen).

## Стек
- Vite + JavaScript
- Three.js — 3D-сцена
- GSAP — таймлайн анимации
- Целевой формат: 1080×1920, 60 FPS, 9:16

## Запуск
```bash
npm install
npm run dev
```

## Управление временем
Вся анимация привязана к абсолютному времени: `renderFrame(seconds)`. Это позволяет позже рендерить кадры детерминированно и собирать MP4 через FFmpeg.

В браузере добавь к URL `?t=15`, чтобы открыть сцену на указанной секунде. Без параметра воспроизводится полный ролик.

## Первый ролик
Сценарий: «Как ИИ создаёт ответ?» (35–40 секунд). Сейчас это первый визуальный черновик: хук, токенизация, контекст, генерация и финальный тезис. Дикторская дорожка и экспорт MP4 подключаются следующим этапом.
